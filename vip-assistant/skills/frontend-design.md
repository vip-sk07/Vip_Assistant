# Skill: Professional Frontend Design & Development

When building or updating user interfaces (HTML, CSS, React, or JavaScript components):

1. **Rich Aesthetics:**
   - Avoid generic, plain solid colors. Use rich gradients, custom HSL values, sleek dark modes, and soft card shadows.
   - Use Google Fonts (such as Outfit, Inter, or Outfit) instead of default sans-serif browser fallbacks.
   - Employ modern card layouts, subtle borders, and smooth transition animations (transition-all, duration-300).

2. **Micro-animations & Interactive States:**
   - Always style button focus, hover, active, and disabled states.
   - Implement clean transitions for buttons, card hovers, and input fields.
   - Ensure loading states are visually represented (e.g. glowing loading animations, progress indicators).

3. **Responsive Architecture:**
   - Design mobile-first using clean CSS grid or flexbox layouts.
   - Ensure elements do not overflow on screens narrower than 360px.
   - Keep forms clean with consistent padding and rounded corners (`border-radius: 8px` / `rounded-lg`).
